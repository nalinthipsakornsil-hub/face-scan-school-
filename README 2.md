# Face Scan Attendance สำหรับ iPad

นี่คือ PWA (เว็บแอปที่ติดตั้งลงหน้าจอ Home ของ iPad ได้)

## วิธีใช้
1. แตกไฟล์ ZIP
2. นำโฟลเดอร์ขึ้นโฮสต์แบบ HTTPS
3. เปิดผ่าน Safari บน iPad
4. กดปุ่ม Share (สี่เหลี่ยมมีลูกศรขึ้น)
5. เลือก “Add to Home Screen / เพิ่มไปยังหน้าจอโฮม”
6. เปิดจากไอคอนบนหน้าจอโฮมได้เหมือนแอป

## ฟังก์ชัน
- ออกแบบสำหรับหน้าจอ iPad
- ใช้กล้องเมื่อเว็บไซต์ได้รับสิทธิ์และเปิดผ่าน HTTPS
- จำลองการสแกนหน้าเพื่อสาธิตโครงงาน
- บันทึกประวัติในอุปกรณ์ด้วย localStorage
- ทำงานแบบ PWA

หมายเหตุ: เวอร์ชันนี้ยังไม่ใช่ระบบจดจำใบหน้าจริง
